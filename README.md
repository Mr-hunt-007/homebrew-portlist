# homebrew-portlist

A Homebrew tap for [portlist](https://github.com/Mr-hunt-007/portlist): every
port on this machine, and where it came from.

```sh
brew tap Mr-hunt-007/portlist https://github.com/Mr-hunt-007/homebrew-portlist
brew install portlist
```

`Formula/portlist.rb` is generated by `scripts/release.sh` in the main repo,
which stamps the checksum from the tarball GitHub actually serves for the tag.
